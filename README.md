# 🚀 Crypto Website

A modern and responsive cryptocurrency website built using HTML, CSS, and JavaScript. This project provides a clean interface with multiple pages for exploring crypto-related content.

## ✨ Features

- 🏠 Home page
- ℹ️ About Us page
- 📞 Contact page
- 🎨 Modern and responsive UI
- 📱 Mobile-friendly design
- 🖼️ Image assets included
- ⚡ JavaScript-based interactions
- 🔗 Multi-page website navigation
- 🎯 Easy to customize

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
